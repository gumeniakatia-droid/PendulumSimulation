# Моделювання математичного маятника (SFML + C++)

Лабораторна робота 5. Варіант 2.

Програма моделює рух математичного маятника з можливістю зміни довжини підвісу та початкового кута відхилення.

## Технології

- C++17
- SFML 3 (Graphics, Window, System)
- CMake
- vcpkg
- Visual Studio 2022

## Як зібрати та запустити

1. Встановіть [vcpkg] і задайте змінну середовища `VCPKG_ROOT`.
2. Відкрийте папку проєкту у Visual Studio (File  Open  Folder).
3. Дочекайтеся конфігурації CMake (vcpkg автоматично встановить SFML).
4. Натисніть Build → Build All, потім Run.

## Керування

Клавіша    Дія                              

 ↑ / ↓     Збільшити / зменшити довжину L   
 ← / →     Змінити початковий кут           
 Space     Пауза / продовжити               
 R         Перезапуск симуляції             

## Що відображається

- Поточна довжина підвісу
- Поточний кут відхилення
- Кутова швидкість
- Теоретичний і виміряний період коливань
- Час моделювання
